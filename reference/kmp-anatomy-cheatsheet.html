A target's binary is all source sets labelled with it, compiled together. Platform source sets see commonMain; commonMain never sees them.

shared/build.gradle.kts

plugins {
    id("org.jetbrains.kotlin.multiplatform")
    id("com.android.kotlin.multiplatform.library")   // not com.android.library
}
kotlin {
    android { namespace = "…shared"; compileSdk = 37; minSdk = 26 }   // not androidLibrary { }
    listOf(iosArm64(), iosSimulatorArm64()).forEach {
        it.binaries.framework { baseName = "Shared"; isStatic = true }  // Swift: import Shared
    }
}

expect / actual

// commonMain                         // androidMain                       // iosMain
expect fun platformName(): String     actual fun platformName() = …Build…   actual fun platformName() = …UIDevice…

Same package, same signature, an actual for every target, or the build fails. Use it for small leaf facts; for anything with behaviour, prefer an interface + injected implementation (a port, from Lesson 06). Expected classes are Beta.
