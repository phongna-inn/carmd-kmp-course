Self-check

Label each part: the class, the field, the constructor, the interface, the callback method, the override.

public class DeviceScanner {
    private final BluetoothAdapter adapter;

    public DeviceScanner(BluetoothAdapter adapter) {
        this.adapter = adapter;
    }

    public interface ScanCallback {
        void onDeviceFound(String name, int rssi);
    }

    public void startScan(ScanCallback callback) {
        callback.onDeviceFound("Device 1", -60);
    }

    @Override
    public String toString() {
        return "DeviceScanner";
    }
}
Answer key

public class DeviceScanner: the class. private final BluetoothAdapter adapter: an immutable field. public DeviceScanner(BluetoothAdapter adapter): the constructor (no return type, class name). public interface ScanCallback: a nested one-method interface. onDeviceFound: the callback, called back on whatever object the caller passed in. @Override … toString(): replaces Object's inherited method.
